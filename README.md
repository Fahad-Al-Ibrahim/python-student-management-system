# Student Management System

A beginner Python project that manages student records using JSON file storage.

## Features

- Add student records
- View and search students
- Add marks and calculate results
- Update student information
- Delete student records
- Save data in a JSON file

## Technologies Used

- Python
- JSON for data storage

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:

   `python relearn.py`

## What I Learned

This project helped me practise Python dictionaries, functions, file handling, JSON, user input, and basic CRUD operations.
